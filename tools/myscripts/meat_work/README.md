3. 脚本说明
- 运行脚本后产生的文件结构如下：
```
./data/
  meat.jpg           # 输入大图（拼排图）
  bms_crops/         # 自动生成：网格切分后的子图
  bms_white/         # 自动生成：白肉掩码
  bms_red/           # 自动生成：红肉掩码
  bms_out/           # 自动生成：彩色叠加可视化
  bms_results.xlsx   # 自动生成：结果表
```
PS: 注意 template 目录下的模板文件有助于分割效果提升
- 技术思路

借助 OpenCV 和 NumPy 实现对肉类拼排图的红白肉比例分析。

首先将整张大图按行列切分成小格子，再在每个格子里通过颜色阈值检测黑色边框，截取出黑框内的区域作为 ROI。接着在 ROI 内用 双路红色检测：一条路径是 HSV 色彩空间的双区间阈值，另一条是 Lab 空间的 a 通道 + Otsu 自适应阈值，两者取并集后经过形态学操作（闭运算、膨胀、填洞、最大连通域、轻度腐蚀）得到完整的“红肉整体”。再用严格的 HSV 红色阈值提取“红肉核心”，两者相减得到“白肉”。最后统计红、白区域的像素比，输出掩码图、可视化叠加图，并将结果写入 Excel 表格。

核心流程就是：网格切分 → 黑框检测 → 红色区域分割（HSV + Lab） → 白/红分离 → 像素比计算与结果输出。
